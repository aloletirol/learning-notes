This is your own little Notion for things you learn with **Claude Code**.

## Every note is a file
Each note is a Markdown (`.md`) file in the `notes/` folder of your GitHub repository. The top of the file has a small header:

```
---
title: My note title
tags: claude-code, git
date: 2026-10-27
---
```

Everything below the header is your note.

## Three ways to add a note
1. **In this app:** click **+ New note**, write, then **Save to GitHub** → click **Commit changes** on GitHub.
2. **Ask Claude Code:** "Save a note about what I learned today", then "commit and push it".
3. **On github.com:** open the `notes/` folder → **Add file** → **Create new file**.

## Markdown cheat sheet
- `**bold**` → **bold**
- `*italic*` → *italic*
- `- item` → a bullet list
- `` `code` `` → `code`
- `## Heading` → a heading
- `- [ ] task` → a checkbox

> Tip: use the tags in the sidebar to filter, and the search box to find anything.
