# 📓 Learning Notes

A small Notion-style app for notes about what I learn with Claude Code.

- Notes are Markdown files in [`notes/`](notes/).
- The app is plain HTML/CSS/JS — no install or build step.
- Hosted free with GitHub Pages.

New to GitHub? Start with **[GITHUB-GUIDE.md](GITHUB-GUIDE.md)**.

## Preview on your computer

```bash
python3 -m http.server 8000
```

Then open <http://localhost:8000>.

## Setup

Put your GitHub username in [`config.js`](config.js).
